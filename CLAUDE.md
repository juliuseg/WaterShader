## Project overview

This is a Unity 6 (`6000.3.22f1`) URP (Universal Render Pipeline, `com.unity.render-pipelines.universal` 17.3.0) 3D project exploring ocean/water rendering, built around a Gerstner-wave shader tutorial (PolyToots "GerstnerWaves"). There is almost no custom C# gameplay code yet — the project is primarily Unity assets: Shader Graphs, materials, a terrain-based demo scene, and prop models. Custom C# code consists only of the stock Unity template Readme system (`Assets/TutorialInfo/Scripts/Readme.cs`, `Assets/TutorialInfo/Scripts/Editor/ReadmeEditor.cs`).

## Working with this repo

This is a Unity project, not a CLI/package repo — there is no `package.json`/build script and no test suite checked in (only the stock `com.unity.test-framework` package dependency, with no tests written). Day-to-day work happens inside the Unity Editor (Editor version `6000.3.22f1`), not the terminal:

- Open the project in Unity Editor `6000.3.22f1` (or newer 6000.3.x) via Unity Hub, or `Unity -projectPath /Users/juliuseg/Water`.
- "Build" = Unity's Build Settings (File > Build Settings) — there's no scripted CLI build in this repo.
- To batch-build/test from the CLI, use Unity's `-batchmode -quit -executeMethod` or `-runTests` flags against the installed Editor binary; there is no wrapper script for this here.
- `.csproj`/`.slnx` files at the repo root are Unity-generated (via `com.unity.ide.rider`/`com.unity.ide.visualstudio`) for IDE tooling only — do not hand-edit them, they're regenerated by Unity.

## Architecture

- **`Assets/PolyToots_Tutorials/GerstnerWaves/`** — the actual water content. `GerstnerScene.unity` is the demo scene (terrain, ocean plane, pirate ship, baked lighting). `Shader/` holds the Gerstner ocean Shader Graphs (`Ocean_Gerstner.shadergraph`, plus a reusable `PT_Gerstner.shadersubgraph` and a simplified `Tutorial_Basic/Gerstner_Tutorial.shadergraph`) and their materials/normal maps. `TerrainTextures/` and `SceneFluff/` hold the terrain layers and scene-dressing assets (boats, terrain, post-process volume) used by that scene.
- **`Assets/Gerstner/`** — a standalone Gerstner Shader Graph + material, separate from the PolyToots tutorial assets above.
- **`Assets/Rocks/`** — rock prop models (FBX, with LOD variants `_lod1`/`_lod2`/`_lod3`) and their PBR textures (albedo/normal/roughness/AO), used as scene dressing.
- **`Assets/Scenes/SampleScene.unity`** — the default empty Unity template scene (not the water demo).
- **`Assets/TutorialInfo/`** — Unity's stock "Readme" template system (`Readme` ScriptableObject + custom Editor window shown on project open). Not project-specific logic.
- Wave motion and ocean surface behavior live entirely in the Shader Graph assets under `Shader/`, not in C# — there is no CPU-side wave simulation script. Any change to wave shape/behavior means editing the Shader Graph (Gerstner wave nodes) in the Unity Editor, not writing C#.
